🔌 API Endpoints

            

                
GET/healthHealth check + system stats

                
GET/infoEnvironment details

                
POST/executeRun shell commands

                
POST/file/readRead text files

                
POST/file/writeWrite text files

                
POST/file/uploadUpload binary files

                
GET/file/download/{path}Download files

                
GET/file/list/{path}List directory contents

                
DEL/file/delete/{path}Delete files/folders

                
POST/packageapt-get install/remove/update

                
GET/processesList running processes

                
POST/processes/kill/{pid}Terminate a process

                
POST/scheduleCreate cron-like scheduled task

                
GET/scheduleList scheduled tasks

                
WS/ws/terminalReal-time WebSocket terminal
